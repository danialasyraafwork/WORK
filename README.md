## SEO

The site includes semantic headings, canonical URL, robots directives, Open Graph/Twitter metadata, Organization/WebSite/WebPage/Service/FAQ structured data, `robots.txt`, and `sitemap.xml`.

## Files

- `index.html` — page content, metadata and structured data
- `styles.css` — responsive styling
- `script.js` — booking, add-ons, address lookup and WhatsApp flow
- `robots.txt` — search crawler rules
- `sitemap.xml` — XML sitemap
- `favicon.svg` — Candy Craze browser icon
